# Proyecto Sudoku
## Kata sobre programación modular en Python, a partir de uno de los ejercicios propuestos en el problem set de la Lesson 3: How to Manage Data del curso Intro to computer science del Prof. Dave Evans @evansuva en Udacity.
### Se trata de investigar y comprender los contextos de ejecución al invocar módulos Python.
----
## Enunciado

### Sudoku [http://en.wikipedia.org/wiki/Sudoku] es un rompecabezas lógico en el que una partida viene definida por un cuadrado de 9 x 9 parcialmente rellenado con dígitos, en el que cada casilla contiene uno de los dígitos 1, 2, 3, 4, 5, 6, 7, 8 o 9.
### Para este ejercicio, vamos a generalizar y simplificar el juego. 
### Define una función, check_sudoku, que toma como entrada una lista cuadrada de listas que representa una solución de un rompecabezas de sudoku de n x n y devuelve el valor booleano True si la entrada es un cuadrado de sudoku válido y devuelve el valor booleano False.
